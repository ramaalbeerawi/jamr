# جمر: موقع الطلبات

موقع مطعم «جمر» بعمّان. الزبون بيطلب أونلاين، والطلب بيوصل لشاشة المطبخ، والزبون بيتابع طلبه مباشرة ويوصله واتساب مع كل خطوة.

## كيف بيمشي الطلب

- الزبون بيختار **سفري** أو **جوا المطعم** (مع رقم طاولة اختياري من 1 لـ 30). ما في توصيل، والزبون ما بيحدد وقت.
- كل طلب إله 4 حالات: **جديد**، **بالمطبخ**، **جاهز**، **تم التسليم**.
- بشاشة المطبخ، الطباخ بيكبس على أي حالة مباشرة، وبيقدر يرجع لورا إذا غلط.
- لما يكبس «بالمطبخ» بيختار وقت التجهيز (10 أو 15 أو 20 أو 30 دقيقة)، وهاد الوقت بيوصل للزبون.
- مع كل حالة جديدة بتنبعت رسالة واحدة للزبون. إذا الطباخ رجّع الطلب لحالة قبل، ما بتنبعت رسالة.
- الطلبات «تم التسليم» بتختفي من شاشة المطبخ بعد ساعة.
- صوت التنبيه للطلبات الجديدة لازم ينشغل بكبسة من زر «شغّل صوت التنبيه»، لأنه المتصفح ما بيسمح بالصوت قبل أول كبسة.

API المطبخ لتغيير الحالة: `POST /api/orders/<رقم>/status` مع `{ "status": 0-3, "readyIn": 10|15|20|30 }` وهيدر `X-Kitchen-Key`.

## قبل ما تنشر الموقع

صورة الرابط (Open Graph) معمولة بمسار نسبي `/assets/hero.jpg`. واتساب وفيسبوك بيحتاجوا رابط كامل، فلما يصير عندك دومين غيّرها بـ `public/index.html` لـ `https://دومينك/assets/hero.jpg`.

## التشغيل

بدك Node.js نسخة 18 أو أحدث. ما في ولا مكتبة لازم تنزّلها، يعني ما في `npm install`.

```
node server.cjs
```

بعدها افتح:

- الموقع: http://localhost:5600
- شاشة المطبخ: http://localhost:5600/kitchen.html

إذا البورت 5600 مستخدم من برنامج تاني، شغّل على بورت غيره:

```
PORT=5601 node server.cjs
```

(على PowerShell: `$env:PORT=5601; node server.cjs`)

## ملف ‎.env

انسخ `.env.example` لملف اسمه `.env` بنفس الفولدر، وعبّيه:

```
KITCHEN_PASS=كلمة-سر-قوية

WA_TOKEN=
WA_PHONE_ID=
WA_API_VERSION=v23.0
WA_VERIFY_TOKEN=
```

| المفتاح | شو هو |
|---|---|
| `KITCHEN_PASS` | كلمة سر شاشة المطبخ. إذا فاضي، الشاشة بتضل مسكّرة. |
| `WA_TOKEN` | توكن WhatsApp Cloud API من Meta. |
| `WA_PHONE_ID` | الـ Phone number ID (مش رقم التلفون نفسه). |
| `WA_API_VERSION` | نسخة الـ API، خليها `v23.0`. |
| `WA_VERIFY_TOKEN` | أي كلمة بتختارها، وبتحط نفسها بإعدادات الـ Webhook عند Meta. |

بعد أي تعديل على `.env` لازم تعيد تشغيل السيرفر.

### إذا ما عبّيت مفاتيح واتساب

السيرفر بيشتغل عادي، والرسائل بتنطبع بالـ terminal بدل ما تنبعت. هيك بتقدر تجرّب كل شي بدون حساب Meta.

### كيف تجيب مفاتيح واتساب

1. ادخل على https://developers.facebook.com واعمل App من نوع Business.
2. ضيف منتج WhatsApp.
3. من صفحة **API Setup** خود الـ Temporary access token (هاد `WA_TOKEN`) والـ Phone number ID (هاد `WA_PHONE_ID`).
4. بوضع التجربة، لازم تضيف رقم كل زبون بدك تبعتله بخانة **To** بنفس الصفحة.
5. للـ Webhook: حط رابط موقعك `https://موقعك/webhook`، ونفس الكلمة يلي حطيتها بـ `WA_VERIFY_TOKEN`.

### أخطاء واتساب المشهورة

السيرفر بيطبع شرح بالعربي لما يصير خطأ، وشاشة المطبخ بتعرض السبب:

- **131030**: رقم الزبون مش مضاف لقائمة الأرقام المسموحة بوضع التجربة. ضيفه من API Setup.
- **131047**: مر أكثر من 24 ساعة على آخر رسالة من الزبون، أو ما بعتلك ولا مرة. واتساب ما بيسمح برسائل نص عادية بهالحالة، بس برسائل Template موافق عليها.
- **190**: التوكن انتهى. التوكن المؤقت بيعيش 24 ساعة بس. اعمل توكن جديد، أو توكن دائم من System User.

## الملفات

```
server.cjs        السيرفر (ملفات، API، SSE، واتساب)
public/
  index.html      صفحة الزبون
  styles.css      الشكل
  app.js          المنيو، التخصيص، السلة، الطلب، المتابعة
  i18n.js         عربي / English
  menu.js         الأصناف والأسعار (السيرفر بيقرأ منه كمان)
  kitchen.html    شاشة المطبخ
  kitchen.js
assets/           الصور والفيديو
data/orders.json  الطلبات (بينعمل لحاله)
```

## تعديل المنيو

كل الأصناف والأسعار والمكونات بملف `public/menu.js`. السيرفر بيحسب السعر من نفس الملف، فالزبون ما بيقدر يغيّر السعر من المتصفح. بعد التعديل أعد تشغيل السيرفر.

صورة كل صنف لازم تكون `assets/menu-<id>.jpg`. صورة كومة كل مكون `assets/layer-<اسم>.webp` على خلفية سودا، والموقع بيشيل الخلفية لحاله. إذا مكون ما إله صورة، ما بينرسم على الخبزة.

## الأمان

- السيرفر بيعرض بس فولدر `public` وفولدر `assets`. ملفات `.env` و `data` و `server.cjs` ما بتنفتح من المتصفح.
- كلمة سر المطبخ بتنقارن بـ `crypto.timingSafeEqual`، وبعد 5 محاولات غلط من نفس الجهاز بتوقف المحاولات دقيقة.
- كل زبون بياخد مفتاح سري لطلبه، وما بيقدر يشوف إلا طلبه.
